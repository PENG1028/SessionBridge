# Workbench State API

Location: `app/console/stage/workbench-state.ts`

The workbench state manages all panes, tabs, and views. It replaces the previous ad-hoc `splitLayout` + `showTerminal` pattern with a recursive layout tree where all views are first-class panes.

## Core Types

### ViewType
```typescript
type ViewType = 'empty' | (string & {});
```
Open-ended string union — known values are dynamically registered via `view-registry.ts`.

### PaneTab
```typescript
interface PaneTab {
  id: string;          // unique, generated by genTabId()
  title: string;       // display title in tab bar
  viewType: ViewType;  // which view component renders this tab
  instanceId?: string; // bound runtime instance (for instance-bound views)
  pluginId?: string;   // future: extension plugin ownership
}
```

### PaneState
```typescript
interface PaneState {
  kind: 'pane';
  id: string;           // unique, generated by genPaneId()
  tabs: PaneTab[];      // all tabs in this pane
  activeTabId: string;  // currently visible tab
  zone: 'main' | 'bottom';
  minSize?: number;     // minimum pane size (used for bottom dock resize)
}
```

### SplitNode
```typescript
interface SplitNode {
  kind: 'split';
  id: string;
  direction: 'horizontal' | 'vertical';
  children: LayoutNode[];
  sizes?: number[];  // relative flex-grow for each child (default: all 1)
}
```

### LayoutNode
```typescript
type LayoutNode = SplitNode | PaneState;
```

### WorkbenchState
```typescript
interface WorkbenchState {
  root: LayoutNode;        // recursive split/pane tree
  activePaneId: string;    // currently focused pane
  bottom: PaneState | null; // bottom dock pane (independent of root)
}
```

## Initial State

### `createInitialState(instanceId?, defaultVType?) → WorkbenchState`
Creates a single-pane workbench with one tab. The tab's view type is the first adapter's mapped view, or the first registered non-empty view, or `'empty'`.

### `createEmptyPane(zone) → PaneState`
Creates a pane containing a single `'empty'` tab. Used when the user opens a new pane before choosing a view.

## Reducer (WorkbenchAction)

The state is mutated through a single `workbenchReducer(state, action)` function:

```typescript
type WorkbenchAction =
  | { type: 'FOCUS_PANE'; paneId: string }
  | { type: 'CLOSE_TAB'; paneId: string; tabId: string }
  | { type: 'SPLIT_PANE'; paneId: string; direction: 'horizontal' | 'vertical'; newInstanceId?: string; viewType?: string }
  | { type: 'UNSPLIT_PANE'; paneId: string }
  | { type: 'ADD_TAB'; paneId: string; tab: PaneTab }
  | { type: 'SET_ACTIVE_TAB'; paneId: string; tabId: string }
  | { type: 'SET_TAB_VIEW'; paneId: string; tabId: string; viewType: ViewType; title: string; instanceId?: string }
  | { type: 'ADD_EMPTY_PANE' }
  | { type: 'ADD_BOTTOM_PANE'; tab?: PaneTab }
  | { type: 'SET_BOTTOM_HEIGHT'; height: number }
  | { type: 'REMOVE_PANE'; paneId: string }
  | { type: 'CLOSE_BOTTOM_PANE' }
  | { type: 'SPLIT_PANE_VERTICAL'; paneId: string; newInstanceId?: string }
  | { type: 'SPLIT_PANE_HORIZONTAL'; paneId: string; newInstanceId?: string }
  | { type: 'REORDER_TABS'; paneId: string; tabId: string; targetId: string }
  | { type: 'CLEAR_INSTANCE_TABS'; instanceId: string };
```

### Action Behaviors

| Action | Behavior |
|--------|----------|
| `FOCUS_PANE` | Sets `activePaneId` |
| `CLOSE_TAB` | Removes tab from pane; if last tab, removes the entire pane. On pane removal, focuses the first remaining pane. |
| `SPLIT_PANE` | Splits the target pane into a `SplitNode` with the original pane + a new pane side by side |
| `UNSPLIT_PANE` | Collapses the split containing the pane, keeping only the targeted pane |
| `ADD_TAB` | Appends a tab to a pane and activates it |
| `SET_ACTIVE_TAB` | Changes which tab is visible in a pane |
| `SET_TAB_VIEW` | Transforms a tab's viewType (used when user picks a view for an empty tab) |
| `ADD_EMPTY_PANE` | Adds a new empty pane to the root split |
| `ADD_BOTTOM_PANE` | Creates the bottom dock with an optional initial tab |
| `REMOVE_PANE` | Removes a pane from the tree; if last pane, collapses the entire tree |
| `CLOSE_BOTTOM_PANE` | Sets `bottom: null` |
| `SPLIT_PANE_VERTICAL` / `SPLIT_PANE_HORIZONTAL` | Convenience wrappers for `SPLIT_PANE` |
| `REORDER_TABS` | Drag-and-drop tab reorder within a pane |
| `CLEAR_INSTANCE_TABS` | Sets all tabs bound to `instanceId` to `'empty'` viewType (used on instance kill) |

## Tree Helpers

| Function | Signature | Purpose |
|----------|-----------|---------|
| `findPane` | `(node: LayoutNode, paneId: string) => PaneState \| null` | Recursively find a pane by ID |
| `visitPanes` | `(node: LayoutNode, fn: (pane: PaneState) => void) => void` | Visit all panes in the tree |
| `findPaneByInstance` | `(state: WorkbenchState, instanceId: string) => PaneState \| null` | Find pane containing a tab bound to instanceId |
| `ensureInstanceTab` | `(state: WorkbenchState, instanceId, title?, defaultViewType?) => WorkbenchState` | Add a tab for an instance if none exists, reusing the active pane |

## ID Generation

| Function | Pattern |
|----------|---------|
| `genPaneId()` | `pane_{counter}_{timestamp36}` |
| `genTabId()` | `tab_{counter}_{timestamp36}` |
